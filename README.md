# UrukCode

Free QR code and barcode generator. Create QR codes (URL, text, WiFi, vCard, email, phone, SMS, location) and barcodes (CODE128, EAN-13, EAN-8, UPC, ITF, CODE39, CODE93, MSI, Pharmacode, Codabar). Decode QR from images. Export PNG/SVG.

## Quick Start

```bash
git clone https://github.com/umaer-islam/urukcode.git
cd urukcode
npx serve .
```

Open `http://localhost:3000` in your browser. No build step required.

## Features

- **QR Generator** — URL, text, WiFi, vCard, email, phone, SMS, GPS location
- **Barcode Generator** — CODE128, EAN-13, EAN-8, UPC, ITF, CODE39, CODE93, MSI, Pharmacode, Codabar
- **QR Decoder** — Upload an image to decode its QR content
- **Export** — Download as PNG or SVG
- **Themes** — Dark and light mode (auto-detects system preference)
- **Keyboard Shortcuts** — Ctrl+1/2/3 to switch modes
- **100% Private** — Everything runs in your browser, no server calls
